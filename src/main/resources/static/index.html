Triage & assignment

    A focused, shared workspace

    Members create issues, read their own reports, and add comments.

    Administrators review all issues, assign work, set priorities, and change status.

    Each change has an actor and a timestamp. If another administrator updates an issue first, you will be asked to reload before saving.

    This demonstration uses fictional accounts. The sample usernames and password are public; do not use this workspace for real reports. Data is shared between visitors and is stored in a database.
